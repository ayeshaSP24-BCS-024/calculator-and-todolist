# Calculator & Task Manager Web Application

A simple and user-friendly web application that combines two useful tools in one website: a **Calculator** for performing mathematical operations and a **Task Manager** for organizing and managing daily tasks.

## 📌 Project Overview

This project was created as a practical web development project to demonstrate the use of frontend web technologies and interactive user interfaces.

The website provides two main features:

* 🧮 **Calculator** – Perform basic mathematical calculations.
* ✅ **Task Manager** – Create, manage, complete, and delete tasks.

The application is designed with a clean and responsive interface so that it can be used on different screen sizes.

## ✨ Features

### 🧮 Calculator

The calculator allows users to perform common mathematical operations, including:

* Addition
* Subtraction
* Multiplication
* Division
* Decimal calculations
* Clear/reset functionality
* Interactive calculator buttons
* Display of the current calculation/result

### ✅ Task Manager

The Task Manager helps users organize their tasks.

Users can:

* Add new tasks
* View all added tasks
* Mark tasks as completed
* Delete tasks
* Manage multiple tasks
* Easily track pending and completed tasks

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and user interaction

## 🚀 How to Run the Project

### 1. Download or Clone the Project

Download the project files to your computer or clone the repository.

### 2. Open the Project

Open the project folder in a code editor such as **Visual Studio Code**.

### 3. Run the Website

Open `index.html` in a web browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.

### 4. Use the Applications

From the website, users can access:

* **Calculator**
* **Task Manager**

Both tools can be used directly through the browser.
